# A simple brochure website
[aste.by](https://aste.by/) is a brochure website for my father, who is an engineer programmer.

This is my very first experience in web development, so the site is pretty simple. Though, I tried hard to create an eye-pleasing design that has no unnecessary details and to make code work smoothly. I'm doing my best to maintain the website.

Currently the only site's language is Russian. I could make English localization, but the target audience is different.

## About the stack

The site is made with pure HTML and CSS for front-end and JS with JQuery for back-end. I also have tried Bootstrap for CSS, but ended up having my styles broken because of it, so it's been banished.
