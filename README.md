# A simple brochure website
[aste.by](https://aste.by/) is a brochure website for my father, who is an system administrator.

This is my very first web development experience, so the site is pretty simple. However, I tried hard to create an eye-pleasing design that is free of unnecessary details and to make the code work smoothly. I'm doing my best to maintain the website.

Currently the site's only language is Russian. I could add an English localization, but the target audience is different.

## About the stack

The site is made with pure HTML and CSS for front-end and JS with JQuery for interactivity. I also tried Bootstrap for CSS, but ended up having my styles broken because of it, so it's been banished.

## Key features
- A complete website for introducing a person working as a system administrator
- Thoughtfully created design, trying to fit the technical topic, be well-readable and minimal
- A feedback form to ask for a service
- Mobile and tablet layouts ready to use along with the desktop one
- Everything I could think of to improve convenience and positive user experience

For me, being completely new to web dev, some of these implemented features are important - yeah, I know they can be simple. But I ain't gonna stop here.
